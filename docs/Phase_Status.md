## Conventions

- "Shipped" means code merged to `main` and at least one manual run observed.
- Phase numbering follows the SEA 4.x sub-phase scheme (a/b/c/d). Future phases continue from there.
- If an item moves status, note the date in [Decision_Log.md](./Decision_Log.md) only if the reason is non-obvious.
